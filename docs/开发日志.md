- **涉及模块**：用户与认证（4.1）、项目脚手架（8 P0）
- **涉及文件**：
  - 后端：`apps/server/internal/{config,httpx,health,db,user,auth,middleware,userapi,router,testutil}`、`apps/server/cmd/server/main.go`、`apps/server/Dockerfile`、`apps/server/.golangci.yml`
  - 前端：`apps/web/src/{api,stores,router,layouts,components,views}`、`apps/web/src/validation.ts`

  - 环境：`docker/docker-compose.yml`、`docker/postgres/init.sql`、`.env.example`、`README.md`
- **文档更新**：`DEVELOPMENT.md` 2.1（版本说明）、2.3（仓库现状）、2.4（错误码）、3.1（实现差异）、4.1（关键接口与实现差异）、9（M0 状态）；`docs/任务清单.md` M0 全部任务。
- **实现差异**：
  - 业务接口统一挂在 `/api` 前缀下，`/health` 不加前缀。
  - 注册成功后直接返回令牌（自动登录），响应与登录相同。
  - 用户名限定为 3–32 位字母、数字、下划线，统一存小写；邮箱存小写。唯一性不区分大小写。
  - 登录字段为 `account`，可填用户名或邮箱。
  - 新增 `GET /api/admin/users`（超级管理员的用户分页列表）。
  - `go.mod` 要求 Go 1.26（最新 go-redis、golang.org/x/* 依赖所需），符合规格「Go 1.22+」。
  - 本地 docker compose 中 PostgreSQL 映射到宿主机 5433、Redis 映射到 6380，避免与本机已有服务冲突。
- **待办**：
  - 头像上传（依赖 MinIO，安排在 M5-8）；目前只能填写头像链接。
  - 修改密码接口未实现；吊销用户全部 refresh token 的能力（`RefreshStore.RevokeAll`）已具备。
  - 被封禁用户已签发的 access token 在过期前（最长 15 分钟）仍可使用。
  - 个人主页中的徽章、称号字段在 M3 前固定为空。
