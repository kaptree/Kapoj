# 题库批量管理与题包

## 功能

- 题库页“批量管理”：拥有 `problem.manage_all` 的管理员可多选题目，批量公开、隐藏、删除或下载。
- 题目详情右侧“题目题包”卡片：显示格式版本、文件数和大致大小；题目创建者或 `problem.manage_all` 可下载单题 ZIP。
- 导入页支持 kapOJ 题包和 HydroOJ 题包；可选择“导入后立即公开”。
- kapOJ 题包 v1 可完整往返：题面、格式、提示、样例、测试数据、checker、附件、题面图片、客观题答案、官方题解与价格。

## 权限

| 操作 | 权限 |
| --- | --- |
| 导入题包 | `problem.create` |
| 导入后立即公开 | 额外需要 `problem.publish`；无权限提交 `publish=true` 返回 403 |
| 批量管理/批量下载 | `problem.manage_all` |
| 单题下载 | 题目创建者或 `problem.manage_all` |

题包包含测试数据、checker、答案与题解，属于敏感文件，只通过鉴权接口下载，响应设置 `Cache-Control: private, no-store`。

## kapOJ 题包 v1

单题包：

```text
manifest.json
statement.md
input_format.md
output_format.md
hint.md
samples.json
answers.json
testdata/meta.json
testdata/001.in
testdata/001.out
checker/checker
attachments/<safe-name>
images/<safe-name>
solution.md
solution_code.txt
```

- `manifest.json` 的 `format` 为 `kapoj-problem`，`formatVersion` 为 `1`。
- `testdata/meta.json` 记录每个测试点的 `sortOrder`、`score`、`isSample` 与输入/输出文件名。
- 题面中的站内图片导出为 `kapoj-package://images/<file>`，导入后改写为新题目的 `/api/problems/<id>/assets/<attachment-id>`。
- 不导出数字 ID、创建者、提交/通过统计、提交记录等运行时数据。

批量包：

```text
manifest.json          # format=kapoj-problems
problems/<slug>/...    # 每道题一个单题包
```

导入时自动识别根目录或单层目录中的 kapOJ manifest；没有 kapOJ manifest 且存在 `problem.yaml` 时按 HydroOJ 题包处理。

## 导入规则

- 新题默认未公开；覆盖导入会保留原题目 ID、创建者和提交统计，替换题面、测试数据、checker、附件、题面图片与官方题解，并强制先下线。
- 冲突策略：
  - `ask`：存在同名 slug 时只返回冲突，不写库。
  - `skip`：跳过冲突题。
  - `overwrite`：按 `overwriteSlugs` / `skipSlugs` 覆盖或跳过；仍需创建者或 `problem.manage_all` 权限。
- “导入后立即公开”对新建和覆盖题逐题尝试发布；缺少测试点、特判题缺 checker、被付费/活跃学习路线引用等失败只影响该题，返回 `publishError`，不回滚其他已导入题目。
- 单题导入失败会清理该题已写入的测试数据、附件和 checker；不影响其他题目。

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/problems/import/hydro` | HydroOJ 题包；支持 `publish` |
| POST | `/api/problems/import/package` | kapOJ/HydroOJ 自动识别；支持 `publish` |
| GET | `/api/problems/{id}/package/info` | 题包格式、文件数与大致大小 |
| GET | `/api/problems/{id}/package` | 单题 ZIP |
| POST | `/api/problems/bulk/actions` | `publish` / `hide` / `delete` |
| POST | `/api/problems/bulk/export` | 一次最多 100 题的总 ZIP |

批量操作逐题独立执行，部分成功是正常结果。删除规则：

- 无提交记录：物理删除题目及测试数据、checker、附件文件。
- 有提交记录：只下线，返回 `offlined=true`。
- 被活跃学习路线引用：该题失败并返回原因，其他题目继续执行。

批量导出任一题目不存在时整批拒绝，不返回部分 ZIP，避免越权泄露。

## 限制

- 题包文件不超过 200 MiB，条目数不超过 5000，解压总量默认不超过 1 GiB（可通过导入配置调整实际读取上限）。
- 单题测试点不超过 500 个；单个测试文件不超过 16 MiB；单题测试数据不超过 200 MiB。
- 附件单题最多 50 个；普通附件单个不超过 20 MiB，题面图片不超过 5 MiB；checker 不超过 256 KiB。
