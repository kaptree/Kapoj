# M4-3 轻量社交互动 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付解题思路帖子点赞、用户关注、站内通知，并把论坛回复/点赞/关注接入活跃度与共享分；前端提供点赞按钮、关注/粉丝列表、通知铃铛与通知页。

**Architecture:** 新增 `social` 域（关注、通知、点赞服务）；`problem` 域增加帖子点赞表与 `likeCount/likedByMe`；`activity` 域新增社交活跃度方法与共享榜版本递增；`problemapi` 挂载点赞路由并在回复/删除后调用社交钩子；`socialapi` 挂载关注/通知路由。前端新增 `api/social.ts`、通知铃铛/通知页、点赞/关注 UI。

**Tech Stack:** Go 1.26、Gin、GORM、PostgreSQL 17、Redis、Vue 3、TypeScript、PrimeVue 4、Vitest、Playwright。

**Spec:** `docs/superpowers/specs/2026-11-08-m4-3-social-design.md`

## Global Constraints

- 轻量范围：只做题解帖子点赞、关注、通知；论坛回复即评论，不新增通用评论表。
- 点赞：登录；不能赞自己的帖子（40001）；重复点赞/取消幂等；隐藏题/不存在帖子 404；帖子软删除清理点赞与共享项。
- 关注：登录；不能关注自己；目标必须 active；重复/取消幂等；公开 social/粉丝/关注 GET 对已存在但封禁用户仍可读；摘要不含 email。
- 通知：仅接收者本人可读；类型 `solution_reply`/`solution_like`/`follow`；`dedupe_key` 全局唯一；自己触发自己无通知；帖子删除后通知保留。
- 活跃度：回复 +3、点赞 +1、关注 +2，每类每日上限 20；唯一 ref 去重；取消赞/关注不扣分；best-effort，不阻断主操作。
- 共享分：题解每赞 +5；取消赞扣回；帖子删除移除共享项；共享榜缓存版本递增 best-effort。
- 所有写操作登录；不新增 RBAC 权限码；不推送/不合并。
- 用户文案中文；PrimeVue 4；不新增 UI 依赖。

## Review Focus

1. **点赞一致性**：首次/重复/取消/重复取消；计数；likedByMe；自赞 40001；隐藏题 404；点赞表/共享项/通知/活跃度同事务或可解释的 best-effort 边界。
2. **关注语义**：自己/不存在/非 active；重复与取消幂等；粉丝/关注计数/isFollowing；列表分页/摘要；封禁用户读取；通知 dedupe 不跨接收者冲突。
3. **通知正确性**：三类通知生成/接收者/actor/link/target；自己无通知；重复赞/关注不重复；回复每条一条；未读/单条/全部已读；非本人 404。
4. **活跃度/共享分**：动作/ref 唯一、每日 20 上限、取消不扣；共享项 +5/-5/删除清理；共享榜缓存版本；活跃度榜缓存。
5. **帖子删除清理**：点赞/共享项移除；活动日志保留；通知保留；不残留共享分。
6. **前端**：点赞失败回滚；游客跳登录；关注按钮/粉丝关注 Dialog；通知铃铛未读/轮询/卸载；通知页已读/跳转/空态。
7. **生成类型**：OpenAPI 与后端 DTO 一致；无手写重复。
