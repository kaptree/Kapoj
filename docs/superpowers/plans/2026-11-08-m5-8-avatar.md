# M5-8 头像上传 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用户上传/移除头像；上传优先于外链，非空外链替换上传；头像公开读取；所有现有 `avatarUrl` 展示位置自动更新。

**Architecture:** `users` 增加 `avatar_key`/`avatar_content_type`，`avatar_url` 继续作为有效 URL；`user.Service` 增加可选 storage，上传写随机 key 并更新 URL，公开 `GET /api/users/:id/avatar` 读取；个人资料页与管理员编辑页增加上传/移除/外链语义，`MeDTO`/`ProfileDTO` 增加 `avatarUploaded`。

**Tech Stack:** Go 1.26、Gin、GORM、PostgreSQL 17、本地 storage、Vue 3、PrimeVue 4、Vitest。

**Spec:** `docs/superpowers/specs/2026-11-08-m5-8-avatar-design.md`

## Global Constraints

- 上传 ≤2 MiB，仅 PNG/JPEG/WebP/GIF（magic bytes）；存储 key `avatars/<userID>/<random>`；不接 MinIO。
- 上传成功：`avatar_url=/api/users/<id>/avatar?v=<unix>`、`avatar_key/contentType` 写入、旧文件 best-effort 删除、`avatarUploaded=true`。
- 外链语义：非空外链替换上传并清空 key/contentType；空外链**保留**上传头像（不得把内部 URL 清空）；移除清空外链与上传。
- 管理员编辑同样：`ProfileDTO.avatarUploaded` 为 true 时表单外链留空；保存空外链保留上传，填写外链替换。
- 公开 `GET /api/users/:id/avatar`；无上传/文件缺失 404；本人上传/移除需登录；不新增权限码。
- 所有现有 `avatarUrl` 展示位置（UserMenu/Profile/榜单/测评/社交）继续读 `avatar_url`，不改查询。
- 图片上传失败/DB 失败清理新文件，旧头像不丢；旧文件删除 best-effort。
- 不新增 UI 依赖；中文文案；PrimeVue 4；不推送/合并；`Export.zip` 保持未跟踪。

## Review Focus

1. **来源语义**：上传→内部 URL；非空外链→替换上传；空外链→保留上传；移除→清空两者。测试：四种状态 + `avatarUploaded` + 内部 URL 不被表单误清。
2. **图片安全/清理**：2 MiB/格式 magic bytes；随机 key；旧文件删除；store/DB 失败旧头像保留/新文件清理；公开读取只有图片字节。
3. **管理员编辑**：`ProfileDTO.avatarUploaded=true` 时外链留空；保存空外链不改上传；填写外链替换；不因内部 URL 触发 URL 校验 40001。
4. **展示回归**：`Me`/`Profile`/社交/榜单/测评的 `avatarUrl` 仍正确；`avatarUploaded` 只在 Me/Profile DTO。
5. **前端**：上传/移除 loading、预览 object URL 清理、外链提示、保存空外链保留、错误 Toast/Message；移动端。
6. **API/OpenAPI**：POST/DELETE `/users/me/avatar`、GET `/users/{id}/avatar`；Me/Profile 字段；错误 401/404/40001；生成类型。
