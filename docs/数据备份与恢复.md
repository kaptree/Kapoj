# 数据备份与恢复

## 功能

- 全平台备份：数据库全部业务表、MinIO 业务桶全部对象，打包为 ZIP 后存入 MinIO 备份桶。
- 账号备份：完整单用户快照，或一个包含全部账号的包。
- 定时任务：每天/每周/每月，只保留最新一份成功包。
- 恢复：服务器最新包或上传 ZIP；全平台恢复前自动生成安全备份。
- AI/邮件加密密钥属于安全材料，统一放在根目录 `.env`，不进入 MinIO/平台备份包；`.env` 必须 0600、git-ignored，并单独安全备份。

入口：管理后台 → 系统 → 数据备份（权限 `system.backup.manage`）。

## 配置

| 配置项（根目录 `.env`） | 默认值 | 说明 |
| --- | --- | --- |
| `KAPOJ_MINIO_BUCKET` | `kapoj` | 业务对象桶；平台备份会快照其中全部对象 |
| `KAPOJ_MINIO_BACKUP_BUCKET` | `kapoj-backups` | 备份 ZIP、上传恢复包与安全备份桶 |
| `KAPOJ_BACKUP_DIR` | `<StorageDir>/backups` | 仅 local 后端的备份包目录；MinIO 模式不使用 |
| `KAPOJ_BACKUP_MAX_UPLOAD_BYTES` | 2 GiB | 上传恢复包大小上限 |
| `KAPOJ_BACKUP_MAX_UNCOMPRESSED_BYTES` | 20 GiB | ZIP 解压总大小上限 |
| `KAPOJ_BACKUP_MAX_ENTRIES` | 200000 | ZIP 条目数上限 |

备份包写入 MinIO 备份桶，不进入业务桶快照，避免递归备份。建议给备份桶的 `uploads/` 前缀配置 1 天生命周期规则，自动清理进程中断遗留的临时上传包。

## 存储持久化

业务对象（徽章、头像、证书、站点图片、测试数据/checker、AI 生成数据）统一存放在 MinIO 业务桶；数据库只保存 object key。备份包存放在 MinIO 备份桶。

- `docker/docker-compose.yml` 默认启动 MinIO 并把数据 bind mount 到宿主机 `minio-data`；重建容器不会丢失对象。
- 启动时扫描徽章、头像、证书、站点品牌图片、题目测试数据/checker 和生成测试数据的引用；发现缺失对象会输出 `storage: missing file` 警告。
- 从旧版本迁移：启动 MinIO 后执行 `docker compose ... run --rm server migrate-storage`；迁移只复制业务对象，不删除本地文件。
- MinIO 桶/宿主机 `minio-data` 仍需纳入基础设施备份；平台备份包本身也建议下载到独立介质。
- 根目录 `.env` 含数据库/MinIO 凭证、JWT、AI/邮件加密密钥，必须 0600、git-ignored，并独立安全备份；平台 ZIP 不包含 `.env`。

## 恢复注意事项

建议在全平台恢复期间暂停 judge/其他写入服务，避免恢复窗口内仍有提交或后台任务写入数据库；管理后台会串行化备份/恢复任务，但不能阻止独立进程写入。

- 全平台恢复会替换数据库业务表与业务文件；恢复前自动生成 `safety/` 下的安全备份。后台入口要求输入 `RESTORE`，API 也校验同一确认字段。
- 全平台恢复要求数据库角色允许 `SET session_replication_role = replica`（当前 Docker 的 `kapoj` 用户满足）。
- 恢复成功后服务会自动 graceful shutdown 并重新执行自身；如果运行环境不允许 re-exec，需要配置进程管理器/容器重启策略兜底。
- 账号恢复按原 `user_id` 覆盖资料（含密码哈希）与个人数据；用户名/邮箱冲突会中止，不会静默合并。
- 账号备份不包含该用户创建的题目、比赛、学习路线、公告、任务等平台内容。
- 恢复包与数据库 schema 不一致时拒绝恢复，不会修改现有数据。
- ZIP 不加密，包含密码哈希与业务对象，只能由可信管理员下载并妥善保管；AI/邮件密钥需另行备份。

## 当前数据范围

账号备份包含用户资料、提交、金币流水、成就/任务/徽章/称号、登录记录、学习进度、购买/推荐、通知、关注、评价、证书、活跃/共享/Rating/比赛参与记录、题解互动、测试数据生成记录及头像/证书/生成文件。

## 常见失败

- “备份包与当前数据库 schema 不一致”：升级后不能使用旧版本备份直接恢复。
- “已有恢复任务正在执行”：恢复是全局串行操作，等待当前任务结束。
- “用户名或邮箱已被用户 N 占用”：账号恢复会保留原 user_id，但不会覆盖其他账号的身份字段。
